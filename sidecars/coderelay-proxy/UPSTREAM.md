# CodeRelay sidecar upstream and patch boundary

`third_party/CLIProxyAPI` is the embedded CLIProxyAPI v7.2.140 snapshot. Its
original MIT license and copyright notice are retained in `LICENSE`.

The outer `coderelay-proxy` package contains the CodeBuddy CN relay, request
policy, account selection, model synchronization and the newline-delimited JSON
lifecycle event protocol consumed by the Tauri host.

The sidecar accepts:

- `--config <path>`: runtime configuration generated by CodeRelay;
- `--manifest <path>`: account and API-key manifest generated by CodeRelay;
- `--parent-pid <pid>`: optional host process to monitor.

The sidecar emits a `ready` JSON event on standard output after binding the
HTTP listener. It never writes credentials to standard output. The default
HTTP surface is OpenAI-compatible under `/v1`, with CodeBuddy CN accounts as
the only configured upstream provider in this application.
